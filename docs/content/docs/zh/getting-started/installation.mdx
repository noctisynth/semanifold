---
title: 安装 Semifold
description: 安装最新发布的 Semifold 命令行工具，并确认 smif 命令可以使用。
---

安装后可以使用 `smif` 和 `semifold` 两个等价的命令名称。本文档统一使用较短的 `smif`。

除非需要复现旧环境，否则建议始终安装最新版本。安装脚本会查询 GitHub Releases，并选择标签符合 `semifold-vX.Y.Z` 的最新已发布稳定二进制 Release。脚本不会使用仓库级 `latest` 指针，因为它可能指向 Semifold monorepo 中的其他软件包。

## 推荐方式：安装脚本

<Tabs items={['macOS / Linux', 'Windows PowerShell']}>
  <Tab>

```bash
curl -L https://semifold.noctisynth.org/install/install.sh | sh
```

脚本默认安装到 `$HOME/.local/bin`。如果这个目录尚未加入 `PATH`，请在 shell 配置中添加它。

  </Tab>
  <Tab>

```powershell
irm https://semifold.noctisynth.org/install/install.ps1 | iex
```

脚本默认安装到 `%USERPROFILE%\.local\bin`。如有需要，请把该目录加入 `PATH`。

  </Tab>
</Tabs>

如需修改安装目录，可以向下载后的脚本传入参数：

<Tabs items={['macOS / Linux', 'Windows PowerShell']}>
  <Tab>

```bash
curl -L https://semifold.noctisynth.org/install/install.sh | \
  sh -s -- --install-dir "$HOME/bin"
```

  </Tab>
  <Tab>

```powershell
& ([scriptblock]::Create((irm https://semifold.noctisynth.org/install/install.ps1))) `
  -InstallDir "$HOME\bin"
```

  </Tab>
</Tabs>

## 安装指定版本

只有需要复现特定环境时才需要传入版本。`0.3.1` 和 `v0.3.1` 都会解析到 GitHub Release `semifold-v0.3.1`：

<Tabs items={['macOS / Linux', 'Windows PowerShell']}>
  <Tab>

```bash
curl -L https://semifold.noctisynth.org/install/install.sh | \
  sh -s -- 0.3.1
```

  </Tab>
  <Tab>

```powershell
& ([scriptblock]::Create((irm https://semifold.noctisynth.org/install/install.ps1))) `
  -Version 0.3.1
```

  </Tab>
</Tabs>

默认安装不会选择预发布版本；如确实需要，请显式传入完整的预发布版本号。

## 通过软件包管理器安装

也可以选择当前环境已经信任的软件包仓库：

<Tabs items={['Cargo', 'npm', 'PyPI']}>
  <Tab>

```bash
cargo install semifold
```

  </Tab>
  <Tab>

```bash
npm install --global @semifold/cli
```

  </Tab>
  <Tab>

```bash
pipx install semifold
```

  </Tab>
</Tabs>

npm 包要求 Node.js 20 或更高版本，并会在安装时选择 macOS、Windows 或基于 glibc 的 Linux 所对应的 x64/arm64 N-API binding。该包暂不支持 Linux musl 发行版，请在这些环境中使用安装脚本或 Cargo。

## 验证命令

修改 `PATH` 后请打开一个新 shell，再运行：

```bash
smif --version
```

命令输出已安装的 Semifold 版本且没有报错，就表示安装成功。
