Semifold 是面向跨语言单仓库的版本与发布工具。它连接使用不同清单文件和软件包仓库的软件包，再以整座仓库为范围管理变更集、相关版本修改、变更日志和按依赖发布。

<Availability status="released">
  <strong>当前已发布基线：Semifold 0.3.0-rc.6。</strong>这个版本已经包含仓库内生态插件运行时和 `@semifold/plugin-sdk 0.1.0-rc.0`。
</Availability>

## 整座仓库的版本与发布生命周期

每个软件包的生态适配器负责理解自己的清单文件。Semifold 则负责适配器之间的关系：稳定的软件包身份、跨生态依赖传播、变更意图、发布通道、变更日志、发布顺序和失败恢复报告。

## 推荐阅读顺序

如果你刚接触 Semifold，请先读[介绍](/zh/docs/introduction/)，不要从完整配置参考开始。然后找一座小仓库完成[第一次发布教程](/zh/docs/getting-started/first-release/)。遇到陌生概念时，随时查看[术语表](/zh/docs/concepts/glossary/)。

[命令行文档](/zh/docs/commands/)会逐个解释命令行为，其中的 [CLI 参数参考](/zh/docs/commands/reference/)适合快速查询，不适合作为理解工作流的起点。
