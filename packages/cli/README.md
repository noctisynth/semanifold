# @semifold/cli

Install the Semifold CLI from npm:

```sh
npm install --global @semifold/cli
```

The package provides both `smif` and `semifold`. napi-rs selects a generated platform-specific N-API package at install time; install only `@semifold/cli`.

通过 npm 安装 Semifold CLI：

